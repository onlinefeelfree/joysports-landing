# Joy Sports — แลนดิ้งเพจของพรีเมียมติดโลโก้

หน้าเว็บหน้าเดียวสำหรับแคมเปญ ChatGPT Ads ของ **บริษัท จอย สปอร์ต จำกัด** (เจ้าของแบรนด์ FEELFREE)
กลุ่มเป้าหมาย: ลูกค้าองค์กรที่ต้องจัดหาของพรีเมียมติดโลโก้ และนายหน้า/ตัวแทนที่รับงานมาแล้วต้องหาโรงงานผลิต

เว็บสแตติกล้วน ไม่มี build step — Vercel เสิร์ฟไฟล์ตรงจาก repo นี้ได้เลย

```
index.html     หน้าเว็บทั้งหน้า (CSS + JSON-LD + JS อยู่ในไฟล์เดียว) ← ไฟล์ต้นทางจริง
images/        รูปสินค้า 15 ไฟล์ ใช้ครบทุกใบ ไม่ซ้ำกัน
robots.txt     เปิดให้ search engine และ AI crawler เข้าอ่าน
sitemap.xml    ผัง URL + รูปหลัก
llms.txt       สรุปข้อมูลโรงงานแบบ markdown สำหรับ LLM
vercel.json    cache header
```

> `index.html` ในโฟลเดอร์นี้คือไฟล์ต้นทางเพียงไฟล์เดียว
> ไฟล์ `03-Landing-Page/index.OLD-dark-theme.html` คือดีไซน์เก่าพื้นเข้ม เก็บไว้ย้อนดูเฉย ๆ ไม่ได้ใช้แล้ว

## ⚠️ ต้องเติม 2 ค่าก่อนเปิดแอด

เปิด `index.html` เลื่อนไปท้ายไฟล์ หาบล็อก `CONFIG`

```js
var CONFIG = {
  pixelId:   "",              // ← Pixel ID จาก ads.openai.com → Settings → Conversions
  lineOaId:  "",              // ← LINE OA id ไม่ต้องใส่ @ (ปล่อยว่าง = ซ่อนแถว LINE ทั้งแถว)
  leadEvent: "lead_created"
};
```

ถ้า `pixelId` ว่าง หน้าเว็บจะ **ไม่ยิง conversion เลย** แอดจะวัดผลไม่ได้

| บทบาท | ค่าที่ใช้ | ที่มา |
|---|---|---|
| สีเน้นหลัก | `#FACE03` ทอง | ตัวอักษร OEM บนแบนเนอร์ joysports_021 |

| สีเน้นรอง | `#E76A03` ส้ม | ปุ่มพิลล์บนแบนเนอร์ joysports_022 |

พื้นหน้าเว็บเป็นสีขาว สลับแถบเทาอ่อน และใช้แถบกรมท่าคั่นเฉพาะส่วนสำคัญ
ฟอนต์หัวเรื่องเป็น **Kanit** (ไทยไม่มีหัวแบบหนา ตรงกับที่แบรนด์ใช้บนแบนเนอร์) เนื้อความเป็น IBM Plex Sans Thai

**ห้ามเอา `height:auto` ในกฎ `img` ออก** — แท็ก `<img>` ทุกตัวมี attribute `height` เพื่อกันหน้ากระตุกตอนโหลด
ซึ่งจะชนะ `aspect-ratio` ใน CSS ถ้าลบออก รูปทุกใบจะถูกยืดสูงแล้ว `object-fit:cover` จะซูมตัดเหลือแค่กลางภาพ

## AEO / GEO

สิ่งที่ทำไว้ให้ answer engine หยิบไปตอบได้

- **JSON-LD `@graph`** ในหน้า: `Organization` + `LocalBusiness`, `WebSite`, `WebPage`, `Service` พร้อม `OfferCatalog`, `HowTo` 6 ขั้น และ `FAQPage` 12 ข้อ และ `WarrantyPromise` 2 ปี
- **บล็อก "รับผลิตของพรีเมียมติดโลโก้แบบ OEM คืออะไร"** — ย่อหน้านิยามที่ยกไปตอบได้ทั้งก้อน พร้อมส่วนเทียบ OEM กับ ODM
- **ตารางสรุปบริการ** 14 แถว — ชื่อผู้ผลิต แบรนด์ สินค้าที่ทำได้ รูปแบบการรับงาน ที่ตั้ง ช่องทางติดต่อ
- **FAQ เขียนแบบตอบก่อนอธิบาย** ประโยคแรกตอบตรงคำถามเสมอ
- `robots.txt` เปิดให้ GPTBot, OAI-SearchBot, ChatGPT-User, PerplexityBot, ClaudeBot, Google-Extended ฯลฯ
- `llms.txt` สรุปข้อมูลโรงงานแบบ markdown (ยังเป็นมาตรฐานที่เสนอกันอยู่ ยังไม่มีเจ้าไหนประกาศว่าอ่านจริง แต่ต้นทุนแทบเป็นศูนย์)
- `canonical`, `og:url` แบบเต็ม URL, `og:locale`, `twitter:card`

> **ข้อจำกัดที่ต้องรู้** — ตารางสรุปยังมี 2 แถวที่ไม่มีตัวเลขจริง คือ **MOQ** และ **ระยะเวลาผลิต**
> จุดแข็งของหน้าแบบนี้อยู่ที่ตัวเลขที่จับต้องได้ ถ้าได้ตัวเลขจากลูกค้าเมื่อไหร่ ให้เติมสองแถวนี้ก่อนเรื่องอื่น

## Conversion tracking

พิกเซล OpenAI ฝังในโค้ดโดยตรง ไม่ผ่าน GTM

| พฤติกรรมของคนเข้าเว็บ | Event |
|---|---|
| เปิดหน้า | `page_viewed` |
| กดปุ่มทัก LINE | `lead_created` (`lead_<pageview>_line`) |
| กดเบอร์โทรในหน้าติดต่อ | `lead_created` (`…_phone` / `…_phone2`) |
| กดเบอร์โทรใน hero | `lead_created` (`…_hero_phone`) |
| กดเบอร์โทรในแถบนายหน้า | `lead_created` (`…_agent_phone`) |
| กดปุ่มลอยมุมจอ | `lead_created` (`…_float_phone`) |
| กดลิงก์ Messenger | `lead_created` (`…_messenger`) |
| กดปุ่มคัดลอกเบอร์ | `lead_created` (`…_phone_copy`) |
| กดปุ่ม "ขอใบเสนอราคา" บนหัวเว็บ | ไม่ยิง — แค่เลื่อนหน้า ยังไม่ใช่ลีด |

`event_id` ผูกกับการเปิดหน้าหนึ่งครั้ง + ช่องทาง → กดซ้ำไม่นับเพิ่ม

**ห้ามใส่ฟอร์มคัดกรองก่อนถึงช่องทางติดต่อ** — เคสจริงของติดจรวด ใส่แล้ว conversion ตกจาก 13/วัน เหลือ 0

## UTM ที่ตั้งระดับแคมเปญ

```
?utm_source=chatgpt&utm_medium=cpc&utm_campaign=joysports_corporate&seg=corporate
?utm_source=chatgpt&utm_medium=cpc&utm_campaign=joysports_agent&seg=agent
?utm_source=chatgpt&utm_medium=cpc&utm_campaign=joysports_event&seg=event
```

`seg` สลับป้าย หัวข้อ และคำโปรยบน hero ให้ตรงกับแอดที่คนคลิกมา และติดไปกับข้อความทัก LINE ด้วย
ค่าที่รองรับ: `corporate` · `agent` · `event` · `brand` · `export` (ไม่ใส่ = หัวข้อกลางของกลุ่มองค์กร)
