# Joy Sports — แลนดิ้งเพจของพรีเมียมติดโลโก้

หน้าเว็บหน้าเดียวสำหรับแคมเปญ ChatGPT Ads ของ **บริษัท จอย สปอร์ต จำกัด** (เจ้าของแบรนด์ FEELFREE)
กลุ่มเป้าหมาย: ลูกค้าองค์กรที่ต้องจัดหาของพรีเมียมติดโลโก้ และนายหน้า/ตัวแทนที่รับงานมาแล้วต้องหาโรงงานผลิต

เว็บสแตติกล้วน ไม่มี build step ไม่มี Node ไม่มีฐานข้อมูล
เว็บเซิร์ฟเวอร์ตัวไหนก็เสิร์ฟไฟล์ชุดนี้ได้ตรง ๆ รายละเอียดการนำไปขึ้นโฮสต์อยู่ใน `HANDOVER.md`

```
index.html     หน้าเว็บทั้งหน้า (CSS + JSON-LD + JS อยู่ในไฟล์เดียว) ← ไฟล์ต้นทางจริง
images/        รูปสินค้า 28 ไฟล์ หน้าเว็บเรียกใช้ 27 ไฟล์
               product-buckets.jpg เก็บไว้เฉย ๆ ยังไม่ได้ใช้ ตั้งใจไม่ลบ
robots.txt     เปิดให้ search engine และ AI crawler เข้าอ่าน
sitemap.xml    ผัง URL + รูปหลัก
llms.txt       สรุปข้อมูลโรงงานแบบ markdown สำหรับ LLM
vercel.json    cache header ใช้เฉพาะตอนเสิร์ฟผ่าน Vercel
HANDOVER.md    คู่มือส่งมอบสำหรับฝ่ายไอที เอาไปขึ้นโฮสต์และผูกซับโดเมน
```

> `index.html` ในโฟลเดอร์นี้คือไฟล์ต้นทางเพียงไฟล์เดียว แก้ที่นี่ที่เดียว
> ดีไซน์เก่าพื้นเข้มเก็บไว้นอกรีโปในเครื่องของทีมที่ดูแล ไม่ได้ใช้แล้ว

## AEO / GEO

สิ่งที่ทำไว้ให้ answer engine หยิบไปตอบได้

- **JSON-LD `@graph`** ในหน้า: `Organization` + `LocalBusiness`, `WebSite`, `WebPage`, `Service` พร้อม `OfferCatalog`, `HowTo` 6 ขั้น และ `FAQPage` 10 ข้อ พร้อม `WarrantyPromise` 2 ปี
  ข้อความใน schema ต้องตรงกับข้อความที่เห็นบนหน้าเสมอ แก้ที่หน้าแล้วต้องตามไปแก้ใน schema ด้วย
- **บล็อก "รับผลิตของพรีเมียมติดโลโก้แบบ OEM คืออะไร"** — ย่อหน้านิยามที่ยกไปตอบได้ทั้งก้อน พร้อมส่วนเทียบ OEM กับ ODM
- **ตารางสรุปบริการ** ชื่อผู้ผลิต แบรนด์ สินค้าที่ทำได้ รูปแบบการรับงาน ขั้นต่ำ งบเริ่มต้น ระยะเวลาผลิต กำลังผลิต ที่ตั้ง ช่องทางติดต่อ
- **FAQ เขียนแบบตอบก่อนอธิบาย** ประโยคแรกตอบตรงคำถามเสมอ
- `robots.txt` เปิดให้ GPTBot, OAI-SearchBot, ChatGPT-User, PerplexityBot, ClaudeBot, Google-Extended ฯลฯ
- `llms.txt` สรุปข้อมูลโรงงานแบบ markdown (ยังเป็นมาตรฐานที่เสนอกันอยู่ ยังไม่มีเจ้าไหนประกาศว่าอ่านจริง แต่ต้นทุนแทบเป็นศูนย์)
- `canonical`, `og:url` แบบเต็ม URL, `og:locale`, `twitter:card`

> **ข้อจำกัดที่ต้องรู้** — ขั้นต่ำ 50 ใบ งบเริ่มต้น 5,000 บาท และระยะเวลาผลิต 20 ถึง 30 วัน เติมครบแล้ว
> ที่ยังค้างคือชื่อรุ่นของสินค้า 2 รายการที่โรงงานตอบมาเป็นเครื่องหมายคำถาม เลขมาตรฐาน ISO ที่อ้างไว้ในส่วนทำไมต้องเรา
> และเบอร์ 02-312-1321 ที่โผล่เฉพาะบนปุ่มโทรใน hero ยังไม่ได้ยืนยันว่าเป็นเบอร์กลางของบริษัทหรือไม่

## Conversion tracking

พิกเซล OpenAI ฝังในโค้ดโดยตรง ไม่ผ่าน GTM — `lead_created` ใช้กับ LINE เท่านั้น (เป้า Conversions) โทร/คัดลอกเบอร์แยกเป็น `contact_click`

| พฤติกรรมของคนเข้าเว็บ | Event |
|---|---|
| เปิดหน้า | `page_viewed` |
| กดปุ่มทัก LINE (ทุกลิงก์ line.me / lin.ee) | `lead_created` (`lead_<pageview>_line`) |
| กดเบอร์โทรในหน้าติดต่อ | `custom` → `contact_click` (`contact_<pageview>_phone` / `…_phone2`) |
| กดเบอร์โทรใน hero | `custom` → `contact_click` (`…_hero_phone`) |
| กดเบอร์โทรในแถบนายหน้า | `custom` → `contact_click` (`…_agent_phone`) |
| กดปุ่มโทรลอยมุมจอ | `custom` → `contact_click` (`…_float_phone`) |
| กดปุ่มคัดลอกเบอร์ | `custom` → `contact_click` (`…_copy_<เบอร์>`) |
| กดลิงก์อีเมล (ถ้าเพิ่มในอนาคต) | `custom` → `contact_click` (`…_email`) |
| กดปุ่ม "ขอใบเสนอราคา" บนหัวเว็บ | ไม่ยิง — แค่เลื่อนหน้า ยังไม่ใช่ลีด |

`event_id` ผูกกับการเปิดหน้าหนึ่งครั้ง + ช่องทาง → กดซ้ำไม่นับเพิ่ม

**ห้ามใส่ฟอร์มคัดกรองก่อนถึงช่องทางติดต่อ** — เคสจริงของติดจรวด ใส่แล้ว conversion ตกจาก 13/วัน เหลือ 0

## UTM ที่ตั้งระดับแคมเปญ

```
?utm_source=chatgpt&utm_medium=cpc&utm_campaign=joysports_corporate&seg=corporate
?utm_source=chatgpt&utm_medium=cpc&utm_campaign=joysports_agent&seg=agent
?utm_source=chatgpt&utm_medium=cpc&utm_campaign=joysports_event&seg=event
```

`seg` สลับป้าย หัวข้อ และคำโปรยบน hero ให้ตรงกับแอดที่คนคลิกมา และติดไปกับข้อความทัก LINE ด้วย
ค่าที่รองรับ: `corporate` · `agent` · `event` · `brand` · `export` (ไม่ใส่ = หัวข้อกลางของกลุ่มองค์กร)
